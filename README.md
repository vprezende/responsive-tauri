# Cospectra

**Cospectra** is a modern desktop application built for developers to test website responsiveness and inspect layouts across a full spectrum of screen dimensions in real time.

## ✨ Features

- **Real-time Inspection:** Test responsiveness instantly as you type or adjust layouts.
- **Full Spectrum Dimensions:** Switch seamlessly between custom and preset device screen sizes.
- **Lightweight Performance:** Minimal RAM and CPU footprint compared to browser-based electron alternatives.

## 🛠️ Getting Started

### Prerequisites

Ensure you have the following installed on your machine:

- ⚙️ Runtime: [Node.js](https://nodejs.org/)
- 📦 Package Manager: [Yarn](https://yarnpkg.com/)
- 🛠️ Toolchain: [Rust](https://www.rust-lang.org/tools/install)
- 🏗️ Framework: [Tauri](https://v2.tauri.app/start/prerequisites/)
- 💻 IDE: [VSCode](https://code.visualstudio.com/) or [RustRover](https://www.jetbrains.com/rust/)

### Installation

1. Clone the repository
```bash
git clone https://github.com/vprezende/cospectra.git
```
2. Navigate to the project directory:

```bash
cd cospectra
```

3. Install dependencies

```bash
yarn install
```

4. Run in development mode

```bash
yarn dev
```

5. Build production app

```bash
yarn build
```
